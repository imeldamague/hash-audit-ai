# System card — brouillon

**Usage prévu** : démonstration locale et pédagogique de détection des mauvais schémas de stockage de mots de passe.

**Limites** : détection par motifs, faux positifs possibles, aucune garantie de sécurité, agents sans LLM dans le prototype.

**Données** : exclusivement synthétiques.

**Risques** : injection de consignes dans le code analysé, outils externes non fiables, secrets accidentels. Ne pas exécuter du code cible inconnu ; validation humaine des correctifs.
